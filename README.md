# Minha Casa — Gerenciamento de cômodos

Atividade de Programação Orientada a Objetos em Java: as classes `Casa` e `Comodo`, com uma interface visual em Swing.

## Como executar (JDK 25)

Na pasta do projeto:

```
javac -d bin *.java
java -cp bin Main
```

Também é possível abrir `Main.java` no VS Code (com o Extension Pack for Java) e clicar em **Run**.
